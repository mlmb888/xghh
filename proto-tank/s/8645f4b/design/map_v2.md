# 废城救援 1-1 地图 v2：开放街区（替代 v1 走廊图，v1 文件保留不动）

文件：`level_1_1_v2.json`（字段与 v1 / 原型 `applyLevel()` 完全兼容）、`map_v2.png`、生成脚本 `gen_v2.py` / `render_v2.py`。
校验：`python3 check_level_overlap.py level_1_1_v2.json` → OK（无重叠、障碍都在可走格、H1 安全框全为空地）。

## 为什么改
v1 是 27×96 格（1080×3840pt），宽高比 1:3.6，玩起来像一条走廊，没有自由探索感。v2 改成接近方形的街区：中间是城区枢纽，路往四个方向放射出去，几条路之间成环，营地分在四个方向，先去哪由玩家自己选。

## 结构
- **中心广场**（15–25, 15–22）：整张图的枢纽。北环、西路、东路和横贯东西的大路围着它，构成两个大环。
- **河和桥**：保留。河在第 36–37 行，上面有两座桥：中央大道桥（桥北有路障 hp80，是开局第一个可打破物）和西桥（绕开路障，但路更远）。
- **北端 Boss 场**：10–29 列 × 1–9 行的广场。H2 在 (20,4)，G 营在场边，门朝南。
- **H1**：在 (13,31)，大道西侧的空地。r=2 外加 1 格安全边，范围内全是空地，不压路、斑马线或路障（修了主美提的问题 2）。
- **废车**：两辆都放在路面上当掩体，任何一格都不在楼里（修了主美提的问题 1）。
- **巴士**：放在东路 (33,16)，南北向，1×6 格，即真实比例的 10.5m。西侧留 2 格车道（按问题 3 的拍板：碰撞放大，车身不缩小）。

## 推荐路线与预计时长
- **东线（稳）**：A → 过大道桥 → H1 卸人 → D（补给）→ F（头目）→ G → H2。
  - 共 111 格，约 4440pt，纯行驶约 30s。
  - 救 32 人，扣掉 H1 卸下的 7 人，车上最多 25 人，不超容量。
- **西线（险）**：A → 西桥 → C（12 人 + 精英）→ H1 → 北环 → G → H2。
  - 共 111 格，纯行驶约 30s。
  - 救 28 人。人多但掉血多，还会触发西区伏击 12 只。
- **2★（37 人）需要救 4–5 个营，3★（42 人）几乎要全清**：两条线人数差不多，但一个吃血量、一个吃路程，分岔的取舍是有意义的。
- **时长预估**：纯行驶约 30s，加上破营门、清守卫、送人。
  - 这部分按每营约 12–15s 计，5 营约 60–75s。这是假设值，还没经过数值模拟。
  - 合计中度玩家约 90–120s，和目标一致。
  - time_limit 仍为 240s。具体还请数值用 `m2sim` 实测确认。

## 刷怪方向
- 南：horde_S 追击尸潮，35s 起，沿大道往北推。
- 东 / 西：sp_E / sp_W 两股尸潮沿横路两端涌入，60s 和 75s 起。这两个刷怪点是新增的，type 用的是原型已支持的 wave。
- 伏击：西区 sp_L、东区 sp_R，由触发器触发。
- 北：sp_N，120s 起。
- 尸潮从四个方向来，玩家必须一直移动，和「站着不动会死」一致。
